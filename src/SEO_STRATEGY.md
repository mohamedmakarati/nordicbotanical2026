- Plant detail page → Link to care guide blog post

**Seller Pages → Products**

## 7. SITEMAP STRATEGY

### XML Sitemap Structure
```xml
sitemap.xml
├── Sitemap Index
│   ├── sitemap-pages.xml (Homepage, About, Contact)
│   ├── sitemap-plants.xml (Plant Database - 5000+ items)
│   ├── sitemap-auctions.xml (Active Auctions - updated daily)
│   ├── sitemap-products.xml (Product Listings - updated daily)
│   ├── sitemap-blog.xml (Blog Articles - updated weekly)
│   └── sitemap-sellers.xml (Seller Profiles)
```

### Sitemap Content Strategy

**Pages Sitemap (sitemap-pages.xml)**
- Homepage (priority: 1.0, changefreq: weekly)
- Main hubs (Plants, Auctions, Price Comparison) - 0.9, weekly
- About, Contact, Legal - 0.5, monthly
- Search results (no-index, don't include)
- User account pages (no-index, don't include)

**Plants Database Sitemap (sitemap-plants.xml)**
- All plant detail pages - priority 0.8, changefreq: monthly
- Plant category pages - priority 0.8, changefreq: weekly
- Plant guides - priority 0.7, changefreq: monthly
- Update: Monthly (new plants added)

**Auction Sitemap (sitemap-auctions.xml)**
- Active auctions only - priority 0.9, changefreq: daily
- Don't include ended auctions (link from homepage top 10)
- Update: Daily (new auctions added, ended auctions removed)

**Product Listings Sitemap (sitemap-products.xml)**
- All product detail pages - priority 0.8, changefreq: daily
- Don't include out-of-stock if possible
- Filter for quality (minimum review count if applicable)
- Update: Daily (price changes, availability)

**Blog Sitemap (sitemap-blog.xml)**
- All published blog posts - priority 0.7, changefreq: weekly
- Don't include drafts
- Don't include archived/removed content
- Update: Weekly (new posts)

**Sellers Sitemap (sitemap-sellers.xml)**
- Verified seller profiles - priority 0.7, changefreq: monthly
- Exclude unverified/pending sellers
- Update: Monthly (new sellers verified)

### Sitemap Submission
- [ ] Submit main sitemap index to GSC
- [ ] Add sitemap URL to robots.txt
- [ ] Set sitemap refresh frequency
- [ ] Monitor sitemap errors in GSC
- [ ] Update sitemaps programmatically (daily for auctions/products)
